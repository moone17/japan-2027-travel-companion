Japan 2027 Travel Companion v4.2

This version preserves the v4.1 itinerary, bookings, editing functions, route links, local data key and offline workflow. It refreshes the visual theme to an icy sky-blue winter-night palette and adds the new snowy J logo.

Upload the contents of this folder to the root of your GitHub Pages repository, replacing the previous files. Do not upload the ZIP itself or put the files inside a new subfolder. Open the HTTPS GitHub Pages URL and refresh the page. On iPhone, use Share > Add to Home Screen if you want the PWA icon.

Edits remain saved locally in this browser on this device. Export JSON backups to move edits between devices; this package does not provide automatic cloud sync.
